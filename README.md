# my_jaspr_site

A web project built with **Jaspr** to showcase Flutter web development skills. Jaspr is a modern Dart web framework that feels like Flutter but renders standard HTML and CSS, with support for server-side rendering.

## Running the project

Run your project using `jaspr serve`.

The development server will be available on `http://localhost:8080`.

## Building the project

Build your project using `jaspr build`.

The output will be located inside the `build/jaspr/` directory.
